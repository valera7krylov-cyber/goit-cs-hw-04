
# Домашнє завдання 4 — Багатопотоковий та багатопроцесорний пошук ключових слів

## Опис проєкту

Програма виконує пошук заданих ключових слів у текстових файлах за допомогою багатопотокової та багатопроцесорної обробки.

Мета завдання — порівняти час виконання двох підходів та дослідити особливості їх використання.

## Реалізація

У програмі реалізовано два підходи:

* **Threading** — розподіл файлів між потоками. Результати роботи потоків збираються в спільному списку.
* **Multiprocessing** — розподіл файлів між окремими процесами. Для передавання результатів до головного процесу використовується `multiprocessing.Queue`.

Для пошуку використовується спільна функція обробки файлів. Пошук виконується без урахування регістру символів.

Програма обробляє помилки читання файлів і вимірює час виконання кожного підходу за допомогою `time.perf_counter()`.

## Запуск програми

Для запуску потрібен Python 3.

Виконайте команду в терміналі з кореневої директорії проєкту:

```bash
python main.py
```

Програма виведе результати пошуку ключових слів і час виконання обох підходів.

## Результати тестування

Під час тестування на трьох невеликих текстових файлах отримано такі результати:

| Підхід    | Час виконання |
| --------------- | ------------------------: |
| Multiprocessing |               0.244459 с |
| Threading       |               0.001529 с |

У цьому тесті багатопотокова версія виконалася швидше. Це пояснюється малим обсягом даних і додатковими витратами часу на створення окремих процесів та передавання результатів між ними.

Результати можуть відрізнятися залежно від обсягу даних, обладнання та умов виконання програми.

## Висновок

Обидва підходи забезпечують правильний пошук ключових слів у файлах. Експеримент показав, що для невеликого обсягу даних використання потоків може бути ефективнішим через менші накладні витрати.

Вибір між потоками та процесами залежить від характеру завдання й обсягу даних.
